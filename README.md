# EMA Screener — เว็บไซต์สแกนหุ้นสหรัฐที่ราคาใกล้เส้น EMA

เว็บไซต์ที่แสดงหุ้น S&P 500 ทั้ง 503 ตัวว่าตัวไหนราคากำลังชนเส้น EMA 5/10/20/50/100/200
ปรับเงื่อนไขได้ทันทีในหน้าเว็บ (เลื่อนแถบระยะ %, เลือกเส้น, กรองเทรนด์/เซกเตอร์) โดยไม่ต้องรันใหม่

## เลือกได้ 2 แบบ (ใช้โค้ดชุดเดียวกัน)

โปรเจกต์นี้ให้ทั้งสองทางเลือก เลือกอันที่ชอบ หรือทำทั้งคู่ก็ได้

| | **A. เว็บ static** (GitHub Pages) | **B. แอป Streamlit** (Community Cloud) |
|---|---|---|
| ไฟล์ที่ใช้ | `docs/` | `app.py` |
| ค่าใช้จ่าย | ฟรี | ฟรี |
| ความเร็วตอนเปิด | เปิดติดทันที (ไฟล์นิ่ง + CDN) | ครั้งแรกช้า 10–30 วิ ถ้าแอปหลับ |
| ปรับเงื่อนไข | ทันที ไม่มีดีเลย์ | หน่วงเล็กน้อย (ต้องวิ่งกลับเซิร์ฟเวอร์) |
| กราฟราคารายตัว | ไม่มี | **มี** พร้อมเส้น EMA ซ้อน |
| สรุปตามเซกเตอร์ | ไม่มี | **มี** |
| ต้องดูแล | ไม่ต้องเลย | แอปหลับเมื่อไม่มีคนใช้ ต้องกดปลุก |

**แนะนำ** — ใช้ Pages เป็นหน้าหลักสำหรับดูเร็ว ๆ ทุกวัน และ Streamlit ตอนอยากเจาะดูกราฟรายตัว

## หัวใจที่ทำให้ทั้งสองแบบเร็ว

งานหนัก (ดาวน์โหลดราคา 503 ตัว + คำนวณ EMA) ทำ **วันละครั้ง** บน GitHub Actions
แล้วเก็บผลเป็นไฟล์เล็ก ๆ (`docs/data.js` และ `docs/data.json` ~170 KB, ส่งจริง ~58 KB)

ทั้งเว็บ static และแอป Streamlit อ่านจากไฟล์นั้น **ไม่ยิง Yahoo Finance ตอนมีคนเปิด**
จึงไม่ติดลิมิต ไม่ต้องรอโหลด และเปิดกี่ครั้งก็ไม่มีค่าใช้จ่ายเพิ่ม

> ถ้าให้ Streamlit ไปดึง Yahoo สด ๆ ทุกครั้งที่มีคนเปิด จะรอ 2–4 นาทีต่อครั้ง
> และมักถูกจำกัดคำขอเพราะเป็น IP ของเซิร์ฟเวอร์ที่คนใช้ร่วมกัน — เลยไม่ทำแบบนั้น
> (ยกเว้นกราฟรายตัวที่กดดู ซึ่งยิงแค่ตัวเดียวและแคชไว้ 1 ชั่วโมง)

## โครงสร้างไฟล์

```
ema-site/
├── screener.py                 ← ดึงราคา + คำนวณ EMA เขียนผลลง docs/
├── sp500.csv                   ← รายชื่อหุ้น 503 ตัว (symbol,name,sector)
├── .github/workflows/scan.yml  ← ตั้งเวลาให้ GitHub คำนวณเองทุกวัน
├── app.py                      ← แอป Streamlit (แบบ B)
├── requirements.txt            ← ไลบรารีสำหรับ Streamlit Cloud
├── .streamlit/config.toml      ← ธีมมืดของแอป
└── docs/                       ← เว็บ static (แบบ A — GitHub Pages ชี้มาที่นี่)
    ├── index.html · style.css · app.js
    ├── data.js                 ← ข้อมูลสำหรับเว็บ static
    └── data.json               ← ข้อมูลเดียวกัน สำหรับแอป Streamlit
```

## ขึ้น GitHub และเปิดเป็นเว็บ

**1. สร้าง repo** — github.com → **+** → **New repository** → ชื่อ `ema-site` → **Public** → **Create repository**

**2. อัปโค้ด** (แนะนำใช้ git จะได้ครบทุกโฟลเดอร์ในครั้งเดียว)

```bash
cd ema-site
git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/ema-site.git
git push -u origin main
```

*อัปผ่านหน้าเว็บก็ได้* — ลากโฟลเดอร์ `docs` กับไฟล์ `screener.py`, `sp500.csv` ไปวางในหน้า
Add file → Upload files ส่วน `.github/workflows/scan.yml` ต้องสร้างด้วย **Add file → Create new file**
แล้วพิมพ์ชื่อไฟล์เป็น `.github/workflows/scan.yml` (เบราว์เซอร์ตัดโฟลเดอร์ที่ขึ้นต้นด้วยจุดทิ้ง จึงลากไม่ได้)

**3. เปิด GitHub Pages** — repo → **Settings** → **Pages** → Source: **Deploy from a branch**
→ Branch `main` + โฟลเดอร์ **`/docs`** → **Save**

รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/ema-site/` — บุ๊กมาร์กไว้เลย

**4. สั่งคำนวณข้อมูลจริง** — แท็บ **Actions** → เปิดใช้งาน workflow → คลิก **EMA scan**
→ **Run workflow** → รอ 2–4 นาที เสร็จแล้วหน้าเว็บจะอัปเดตเองภายในไม่กี่นาที

จากนั้นระบบจะคำนวณใหม่ให้เองทุกวันจันทร์–ศุกร์ ตอน 21:30 UTC (04:30 เช้าเวลาไทย)
อยากเปลี่ยนเวลา แก้บรรทัด `cron` ใน `scan.yml` (เวลาไทย = UTC + 7)

## ขึ้น Streamlit Community Cloud (แบบ B)

ใช้ repo เดียวกับข้างบนได้เลย ไม่ต้องแยก

1. เข้า **streamlit.io/cloud** → **Join Community Cloud** → ล็อกอินด้วยบัญชี GitHub
2. กด **Create app** → เลือก **Deploy a public app from GitHub**
3. กรอก 3 ช่อง
   - Repository: `<ชื่อผู้ใช้>/ema-site`
   - Branch: `main`
   - Main file path: `app.py`
4. กด **Deploy** รอ 2–3 นาที (มันจะติดตั้งจาก `requirements.txt` เอง)
5. ได้ลิงก์ `https://<ชื่อที่ตั้ง>.streamlit.app` แชร์ได้เลย

**ข้อควรรู้**
- แอปจะ **หลับเองเมื่อไม่มีคนใช้ราว 7 วัน** ปลุกได้โดยกดปุ่มในหน้าแอปหรือใน dashboard
- ครั้งแรกที่เปิดหลังหลับจะช้า 10–30 วินาที หลังจากนั้นเร็วปกติ
- โควตาฟรี: 1 แอปส่วนตัว + แอปสาธารณะไม่จำกัด, RAM 2.7 GB (โปรเจกต์นี้ใช้ไม่ถึง 200 MB)
- ทุกครั้งที่ push โค้ดขึ้น GitHub แอปจะ deploy ใหม่เอง และเมื่อ Actions อัปเดต `data.json`
  แอปจะเห็นข้อมูลใหม่ภายใน 15 นาที (แคชหมดอายุ)

**สิ่งที่แอปทำได้เพิ่มจากเว็บ static**
- แท็บ **กราฟรายตัว** — เลือกหุ้น ดูกราฟราคา 1 ปีพร้อมเส้น EMA ที่เลือกซ้อนบนกราฟ
- แท็บ **สรุปตามเซกเตอร์** — กราฟแท่งว่าเซกเตอร์ไหนมีหุ้นเข้าเงื่อนไขเยอะ พร้อมคะแนนเฉลี่ย
- ตัวกรองเพิ่ม: ตำแหน่งราคาเทียบเส้น (แนวรับ/แนวต้าน), ราคาขั้นต่ำ, มูลค่าซื้อขายขั้นต่ำ, เส้นเรียงสวย
- ตารางไฮไลต์ช่องที่ชนเส้น เรียง/ค้นหา/โหลด CSV ได้

## ลองในเครื่องก่อน

```bash
pip install -r requirements.txt        # หรือ pip install pandas numpy yfinance streamlit

python screener.py --demo          # ข้อมูลจำลอง เร็ว ไม่ต้องต่อเน็ต
python screener.py                 # ข้อมูลจริงทั้ง 503 ตัว (2–4 นาที)
python screener.py --limit 50      # ทดลองแค่ 50 ตัวแรก
python screener.py --tickers AAPL,MSFT,NVDA
python screener.py --interval 1wk --period 10y   # กราฟรายสัปดาห์
```

ดูผลได้ 2 ทาง

```bash
# แบบ A — เปิดไฟล์ตรง ๆ ไม่ต้องตั้งเซิร์ฟเวอร์
start docs\index.html          # Windows  (macOS ใช้ open docs/index.html)

# แบบ B — เปิดเป็นแอป
streamlit run app.py
```

## วิธีใช้หน้าเว็บ

- **แถบเลื่อน “ระยะที่ถือว่าใกล้”** — หัวใจของเครื่องมือ เลื่อนแล้วผลเปลี่ยนทันที
  0.5% = เฉพาะที่ชนเส้นแบบเป๊ะ ๆ · 3% = มองกว้างขึ้น เจอเยอะขึ้น
- **นับเฉพาะเส้น** — กดปิดเส้นที่ไม่สนใจ เช่นเปิดไว้แค่ 100 กับ 200 เพื่อหาหุ้นที่มาทดสอบแนวรับใหญ่
- **ชนอย่างน้อย** — ตั้ง 3 ขึ้นไปเพื่อหาจุดที่เส้นหลายเส้นมารวมกัน (มักเป็นจุดที่ราคาเคลื่อนไหวแรง)
- **การ์ดแต่ละใบ** — กราฟจิ๋วคือราคา 60 วันล่าสุด · ช่องเลข 6 ช่องคือ EMA ทั้ง 6 เส้น
  ตัวเลขคือระยะห่างเป็น % (บวก = ราคาอยู่เหนือเส้น) **ช่องกรอบเหลือง = เส้นที่ราคากำลังชน**
  แถบสีซ้ายการ์ด เขียว = ขาขึ้น แดง = ขาลง
- **ปุ่มดาวน์โหลด CSV** — ได้เฉพาะรายการที่กรองอยู่ตอนนั้น เอาไปเปิด Excel ต่อได้

**คะแนน** — ชนหลายเส้นยิ่งสูง เส้นยาว (100/200) มีน้ำหนักมากกว่า และบวกเพิ่มถ้าเรียงเส้นสวย/เป็นขาขึ้น

เครื่องมือนี้ช่วยคัดกรองเบื้องต้นเท่านั้น ไม่ใช่คำแนะนำการลงทุน ควรเปิดกราฟดูประกอบทุกครั้ง
